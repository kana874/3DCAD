# Qt専用ワークスペース：最初の実装

状態：試用版。通常版から独立した `?workspace=fusion` で起動します。

FreeCADの形状・拘束・FCStdデータを正本とし、ツールバー、左ブラウザ、右操作パネル、下部履歴をQt内に実装しています。ブラウザ側はモジュールを読み込むだけで、DOMの合成マウスイベントは使用しません。通常版のHTMLパレットとキー割当ては、このモードでは起動しません。

## 現在の操作

1. 「スケッチを作成」→XY/YZ/XZの平面を選び「この平面で開始」。ボディは必要に応じて作成します。
2. R/C/Lで標準の対話作図、または右側の「幅・高さを指定して長方形」「直径を指定して円」で寸法付き図形を作成します。数値指定の位置はスケッチのローカル座標です。位置は必要に応じて追加拘束してください。
3. スケッチ編集中にEを押すと、編集終了から専用の押し出しへ直接進みます。
4. 距離、操作、方向、範囲を選択し、プレビューを確認してOK。Escまたはキャンセルで確定前の変更を戻します。
5. 作成した形状の平面をクリックして「スケッチを作成」を押すと、面にアタッチされたスケッチを開始します。
6. 履歴の押し出し／切り取りをダブルクリックし、距離を変更できます。スケッチも履歴またはツリーから再編集できます。
7. 「標準GUI」は再読み込みせず専用画面を閉じ、元の画面と設定へ戻します。

移動は中ボタン、回転はShift＋中ボタン、拡大縮小はホイールです。入力欄と日本語IMEの入力中は作図キーが割り込みません。Sでコマンド検索を開けます。

通常の3D画面には10 mm間隔・±100 mmのXY床グリッドと、原点を通るX（赤）／Y（緑）／Z（青）軸を表示します。「原点・グリッド」で切り替えられます。スケッチ編集中は標準Sketcherのグリッドへ切り替わります。参照線は選択・保存・書き出しの対象になりません。上部ツールバーはFreeCADのライト／ダークテーマ色に追従します。

## 対応範囲

- 押し出し対象：閉じたスケッチ**全体**。個別領域のクリック選択は未対応。
- 結合、切り取り、最初のソリッドの作成。既存ボディ内のスケッチから別ボディを作る操作は未対応。
- 片側、反転、対称（全長）。切り取りは距離または片側の貫通に対応。
- 数値図形は右パネルで指定します。カーソル横のインライン寸法入力は未対応。
- フィレット、面取り、標準寸法などはFreeCADの標準コマンドを利用する段階です。必要時は標準タスクパネルを表示します。
- 履歴は実フィーチャの作成順表示と再編集に対応。巻戻し、抑制、並べ替え、コンポーネント体系は未対応。
- サーフェス、全ショートカット、F3D互換は今回の実装範囲に含みません。

## データと取消

押し出しは一つの文書トランザクションとして処理します。プレビューの一時オブジェクトは確定・取消で削除されます。プレビュー中だけ既存のブラウザ自動保存を延期し、終了時に元の自動保存処理へ戻します。未確定のプレビューを回復ファイルへ保存しないためです。

面上スケッチはFreeCADのAttachmentSupportを使います。単なる座標コピーではありません。形状変更で参照先自体が失われるケースの修復UIは今後の課題です。

## 配布

Dockerfile.jaが上流画像のHTMLを取得し、scripts/localize_freecad.pyが専用起動スクリプトを差し込みます。play-gui/cad以下はDocker画像とPages成果物へ明示的にコピーします。HTMLスナップショットだけを修正しても公開版に反映されない点に注意してください。

専用UIの起動前に日本語フォント適用を待ち、Pythonの再入ガードを維持します。通常版は既存のまま利用できます。

## 検証

`npm test`：Python単体テスト、Service Worker実行テスト、JS構文検査。

実エンジン試験：`CHROME_PATH=/path/to/chrome node tests/cad_workspace_e2e.cjs _site`

この試験は専用Qtウィジェットの座標を読取専用プローブで取得し、実際のマウスとキーボードで操作します。形状作成をPythonで代行しません。保存・再読込に限りFCStd APIを直接利用し、ブラウザのファイル選択・ダウンロードUIを試験したとは扱いません。

試験条件：1600×1000のLinux headless Chromium、公開版と同じFreeCAD Web 1.0.8／FreeCAD 1.1.3のWASM。Windows/Edgeや8GB実機での快適性・長時間安定性は未検証です。

受入試験：50×30×10 mmの板、面クリックから直径10 mmの貫通穴、履歴から板厚20 mmへの変更、面アタッチメントと貫通穴の追従、Esc取消、FCStd保存・再読込。入力条件の数値は試験用で、一般的な性能値ではありません。

次の実装対象は、領域単位の選択と押し出し、カーソル近傍の寸法入力、複数ボディ、履歴の巻戻しです。
