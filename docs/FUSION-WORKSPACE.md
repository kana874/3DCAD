# Qt専用ワークスペース

起動URL：`?workspace=fusion`。FreeCADの形状カーネル・拘束ソルバー・文書を利用し、操作入口は専用ツールバー、ブラウザ、デザインパネル、履歴へ集約しています。通常URLは従来版です。

## 平面を選んで作図する

「スケッチを作成」でXY・YZ・XZの半透明平面を表示します。ホバーで強調し、平面をクリックすると作図へ進みます。重なった場所では手前の平面を選びます。平面名と右側の平面選択でも確認できます。既存の平面フェイスを先に選んでいれば、その面へ直接スケッチを作ります。Escで平面選択を取り消せます。

上部「作図」で連続線／ポリライン、単独線、中心矩形、円、円弧、楕円、長穴、多角形、スプライン、点を選びます。「修正・拘束」にはエンジンに含まれるSketcherコマンドを登録しています。Lはポリライン、Rは矩形、Cは円、Dは寸法、Tはトリム、Xは補助線です。連続線の線分モードは標準SketcherのMで切り替えます。

右パネルの数値作図では、幅・高さを指定した矩形、中心固定の矩形、直径指定の円を作成できます。「作図」には3点矩形と2点円の座標入力もあります。数値は単位付きで入力できます。矩形の寸法、円の直径はSketcher拘束として残ります。中心矩形は中心点も拘束します。通常矩形・3点矩形の位置や向きは必要に応じて追加拘束してください。

「作図」→「スケッチ表示・スナップ設定」で、そのエンジンが公開する表示・グリッドの設定を切り替えられます。

## 領域を選んで押し出す

スケッチ編集中またはスケッチを選んだ状態でEを押します。閉じた領域を青く表示し、クリックまたは一覧のチェックで対象を選びます。複数選択に対応し、選択中は橙色です。単独の閉じたスケッチは通常の操作を維持するため自動選択します。

「ボディ断面を境界に含める」を有効にすると、元のボディとスケッチ平面の交差輪郭も領域の境界に使います。例えば、直方体上面を横断する開いた線でも、直方体の断面境界と合わせて左右の閉領域を作れます。これは断面の取り込みです。離れた場所にあるエッジを任意方向に投影する機能とは区別してください。その場合は「修正・拘束」の投影コマンドを利用します。

距離、結合／切り取り／新規ボディ、片側／反転／対称、距離／貫通を指定し、プレビューから確定します。貫通は切り取りの片側に対応します。Escで未確定の変更を戻します。結合結果は1つの連結ソリッドが必要です。離れた複数ソリッドを1つのPartDesignボディへ確定することはできません。

開いた輪郭の薄肉押し出し、サーフェス押し出し、対象面までの距離などを統一押し出しダイアログへ統合する作業は残っています。エンジンの追加機能は「ソリッド」「形状・検査」の専用メニューから起動します。

## パネルを戻す・追加機能を使う

「表示」メニューからブラウザ・デザイン・履歴を個別に戻せます。「レイアウトを初期化」は3つを表示して幅も初期化します。全パネルを×で閉じても上部メニューは残ります。表示状態はFreeCADの設定へ保存します。

フィレット、面取り、その他の標準タスクを必要とするコマンドも、専用デザインパネルへ作業ウィジェットを組み込んで実行します。標準GUIへ戻るボタンはありません。測定と設定も「表示」から起動できます。履歴の押し出し／切り取りはダブルクリックで距離を編集し、他のフィーチャはネイティブ編集を専用パネル内で開きます。

上部に収まらないメニューはQtツールバーのオーバーフローへ入ります。S検索からも登録コマンドを探せます。「機能」→「機能セットを読み込む」から表計算・図面・ドラフトなど、配布エンジンに含まれるワークベンチを必要時に読み込めます。読み込まれたコマンドは「機能」の一覧とS検索へ追加され、専用GUIを維持して実行します。検索はコマンド名・内部IDでも行えます。表計算などの2D画面では3D用の原点・グリッドを外し、単文字ショートカットがセル入力に割り込みません。3Dへ戻す場合は既存の3Dタブ、または「機能」→「新しい3Dビュー」を使います。

コマンドの登録と、すべての入力条件の検証は別です。詳細は[FUSION-COVERAGE.md](FUSION-COVERAGE.md)を参照してください。

## データ・再計算・互換性

通常の閉スケッチ全体を押し出す場合は、従来のSketch→Pad/Pocketというネイティブ参照を維持します。部分領域や断面境界を用いる場合は、元スケッチ・境界となるボディフィーチャ・選択領域の参照を保持する`RegionProfile`を生成します。その上でネイティブPad/Pocketを作成します。

領域の参照には、元の曲線と交点で分割された部分の順序を用います。Face番号だけを保存する方式ではありません。選択領域が見つからない場合は無効形状として再選択の必要性を通知します。履歴で押し出しを開き「押し出す領域を再選択」から選び直せます。ツリーの「選択領域」を直接編集することもできます。複雑なトポロジー変更や幾何要素の削除・並べ替えの全ケースで追従を保証するものではありません。

`RegionProfile`の再計算には同梱の`cad_profiles.py`と`cad_core.py`が必要です。このアプリでは起動時に配置し、先に復旧ファイルが開かれた場合もプロキシを復元します。デスクトップ版FreeCADで領域フィーチャを再計算する場合は、両モジュールがPythonからインポートできる環境へ導入してください。依存関係を持たない形状として他ソフトへ渡す場合はSTEP等を書き出します。

押し出し操作は1つのトランザクションで扱い、取消でプレビューと補助形状を戻します。プレビュー中はブラウザの自動保存を延期し、終了後に復帰します。原点軸・床グリッド・平面選択・領域選択の表示は文書へ保存しません。

## 移動・配色・配布

中ボタンで移動、Shift＋中ボタンで回転、ホイールで拡大縮小。ライト／ダークのテーマ色に追従します。入力欄・スピンボックス・日本語IMEの操作中は作図キーが割り込みません。

通常の床グリッドは10 mm間隔・±100 mmのXY面です。原点を通るX（赤）／Y（緑）／Z（青）軸と併せて「原点・グリッド」で切り替えます。スケッチ編集中はSketcherのグリッドへ切り替えます。

Dockerfile.jaが上流画像のHTMLを取得し、scripts/localize_freecad.pyが専用ローダーを挿入します。`play-gui/cad`を全体として配布する必要があります。HTMLスナップショットだけを修正しても公開版へ反映されません。

## 検証

`npm test`でPython単体テスト、Service Workerテスト、JS構文を検査します。

`CHROME_PATH=/path/to/chrome node tests/cad_workspace_e2e.cjs _site`で実WASMの受入試験を実行します。`CAD_TEST_PHASE=baseline`は従来操作、`CAD_TEST_PHASE=workflows`は追加操作に限定した調査用です。通常のCIでは両方を実行します。

Linux headless Chromium、1600×1000、FreeCAD Web 1.0.8／FreeCAD 1.1.3が試験環境です。実際のマウス・キーでウィジェット、平面、領域を操作します。幾何アルゴリズムの入力準備とFCStd保存／再読込は、明示した試験箇所でFreeCAD APIを使用します。ファイル選択・ダウンロードUIを試験したとは扱いません。Windows/Edgeの実機性能、長時間安定性、大規模スケッチの性能は別途確認が必要です。
